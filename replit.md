# HirePath Solutions

A career training marketing site for HirePath Solutions (Nigeria), built with TanStack Start + React + Tailwind CSS v4, backed by Supabase.

## Stack
- **Framework**: TanStack Start (SSR) + TanStack Router (file-based routing)
- **UI**: React 19, Tailwind CSS v4, Radix UI, shadcn/ui components, Framer Motion
- **Backend/DB**: Supabase (auth + database)
- **Build**: Vite 8, Bun

## Running the app
```
bun run dev
```
Runs on port 5000.

## Key routes
- `/` — Home page (programs listing, about, contact/footer)
- `/va-blueprint` — Healthcare Virtual Assistant Blueprint program page
- `/privacy`, `/refund` — Policy pages
- `/sitemap.xml` — Dynamic sitemap
