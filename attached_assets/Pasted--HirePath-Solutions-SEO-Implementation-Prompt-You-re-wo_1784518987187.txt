# HirePath Solutions — SEO Implementation Prompt

You're working on the hirepathsolutions.com codebase — the public marketing site for HirePath Solutions (HPS), a Nigerian career training company. It offers 6 programs: VA Blueprint (Healthcare Virtual Assistant training), AI Automation, UI/UX Design, Cybersecurity, Crypto Trading, and YouTube Automation — training Nigerians for remote roles paid in USD/GBP by US and UK clients. Brand colors are black #000000, white #FFFFFF, gold-yellow #F5A623. Tagline: "Train Smart, Earn More."

## The problem
Right now the whole site is one page with anchor-link sections (#about, #programs, #contact) and a single generic meta title/description shared by everything. That means:
- No individual program can rank in Google for its own keywords, because none of them have their own URL
- The homepage meta description doesn't mention Nigeria, virtual assistant, healthcare, remote, or any term people actually search
- There's no sitemap.xml, robots.txt, or schema.org structured data that I can find
- If this is a client-rendered SPA, content past the hero may not be visible to crawlers at all — this is the same class of problem I already fixed on my other site, De Dreams Hotel, by adding static meta tags and JSON-LD per page

## 3. Structured data (JSON-LD)
Add an `Organization` schema block on the homepage (name, logo, url, `sameAs` for any social profiles), and a `Course` schema block on each program page. Example for VA Blueprint:

```json
{
  "@context": "https://schema.org",
  "@type": "Course",
  "name": "VA Blueprint — Healthcare Virtual Assistant Training",
  "description": "Healthcare virtual assistant training for Nigerians seeking remote roles with US and UK clients.",
  "provider": {
    "@type": "Organization",
    "name": "HirePath Solutions",
    "sameAs": "https://hirepathsolutions.com"
  },
  "hasCourseInstance": {
    "@type": "CourseInstance",
    "courseMode": "online"
  }
}
```

Duplicate this pattern for the other 5 programs with their own name/description.
